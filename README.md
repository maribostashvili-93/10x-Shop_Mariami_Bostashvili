# 10X Shop

10X Shop is an online store being developed as a front-end graduation project. It will use the DummyJSON API to display products and support a shopping flow.

## Tech stack

- React and TypeScript
- Vite
- Tailwind CSS v4
- DummyJSON API (planned)

## Getting started

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Open the local address printed in the terminal. To check the production build or run the linter:

```bash
npm run build
npm run lint
```

On Windows, if PowerShell blocks `npm`, use `npm.cmd` in its place.
